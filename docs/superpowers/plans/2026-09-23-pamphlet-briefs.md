## 共通ルール（全案・必ず守る）

### 目的
高専祭パンフレットに載せる出店紹介カット1枚。印刷時は**約5cm角**になり、他の出店のカット（ほぼ白黒の手描き）と並ぶ。
**5cmに縮めても「店名」と「保成の顔」が一瞬で読めること**が最優先の合格条件。

### 固定情報（これ以外の情報は入れない）
- 店名：**おいしいホットドック屋さん**（「ドック」表記が正式。「ドッグ」にしない）
- 人物名を出すときは **保成**（または佐藤保成）だけを使う
- 使ってよい補足情報：`4年S科教室`／`ホットドッグ 200円`／`チーズ 300円`／`トッピング無料`（各案で指定されたものだけ）
- **文字要素は最大3つ**（店名・一言・補足1つ）

### 技術
- 作業ディレクトリはプロジェクトルート `C:\Users\kabu6\OneDrive\ドキュメント\hotdog-stall`。スクリプトはルートから `node flyers/pamphlet/generate-cut-X.js` で実行する
- 共通ヘルパー `flyers/pamphlet/_lib.js` を使う（`newCut()` で 6in×6in の正方形スライド、`person('番号')`、`addContain/addByHeight/addByWidth/addCover`、`outlinedText`（8方向フチ文字）、`vText`（縦書き）、`addFocusLines`（集中線）、`save()`（safeWriteFile経由）、`HOTDOG`/`CHEESE_HOTDOG`）。**`pptx.writeFile()` を直接呼ばない**
- 書き出し（QA用）：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/export-locked.ps1 -PptxPath "flyers\pamphlet\cut-X.pptx" -OutDir "flyers\pamphlet\_preview"`
  - 他のエージェントと同時に動くので、必ずこの `export-locked.ps1` を使う（`export-slides.ps1` を直接呼ばない）
  - **終了コード2（PowerPointがすでに起動中）が出たら、PowerPointを絶対に閉じず、作業を止めてその旨を報告する**（ユーザーが編集中の可能性がある）。`Stop-Process` 禁止
- 書き出したPNGは Read ツールで**必ず目で見る**
- 5cm確認：PNGを幅240pxに縮めた画像も作って見る（例：`node -e` で pngjs を使って縮小するか、`export-locked.ps1 ... -Width 240 -OutDir flyers\pamphlet\_preview\small`）
- 自分の案のファイル（`generate-cut-X.js`、`cut-X.pptx`、`_preview/cut-X*`）以外は作らない・触らない。`_lib.js` を直したくなったら直さずに報告に書く
- git commit はしない

### 禁止（凡庸を殺す）
- 上に写真／中に見出し／下に情報の三段構成
- 白地や薄ベージュに普通サイズの文字
- 写真を小さな添え物にする（D案を除く）
- ぼかし影とフチ文字の併用
- `shadow: { type: 'inner' }`（ファイルが壊れる）
- 放射線を三角形の大量重ねで描く（線シェイプで）
- 顔に文字を重ねる

### QAチェックリスト（毎サイクル）
1. 文字の意図しない折返し・はみ出し（`wrap:false` と十分な幅）
2. 要素どうしの重なり・衝突、z順（後からaddした物が前面）
3. 重要な文字・顔が端で見切れていないか（断ち落としは意図したものだけ）
4. 写真の切れ端（白い縁・平らな切り口）が見えていないか
5. **幅240pxで見て、店名と顔が読めるか**
6. 3色まで（メイン70:サブ25:アクセント5）に収まっているか
7. 「隣の白黒の手描きカットと並んだとき、真っ先に目に入るか」

**収束するまで**「生成→書き出し→見る→直す」を繰り返す（目安3〜6周）。壊れていないだけで終えない。

## A：ダイナー看板ロゴ（`cut-a`）

**コンセプト**：保成そのものが店のブランドロゴになる。アメリカンダイナーのネオン看板・円形エンブレム。「このロゴの店、知ってる」感。

- 写真：**1000019038**（正面・笑顔）。**円形エンブレムの中にクリップ**する形にし、上下の切り口を必ず円の外に隠す（顔と肩が円に収まるよう、画像を円より大きく置き、円の外側を背景色の図形で覆う or 円リングで縁取る。レンダリングで切り口が見えないことを確認）
- 骨格：画面中央やや上に大きな円エンブレム（直径 約4.2in）。その外周に店名を**アーチ状**に沿わせる（pptxgenjsに円弧テキストはないので、1文字ずつ回転させたテキストボックスを円周上に配置して作る）。上弧に「おいしいホットドック屋さん」
- エンブレム下部に横長リボン帯（やや傾け ±3°以内）に「ASAHIKAWA KOSEN」ではなく **「SINCE 2026・4年S科」** 風の一言。英字はImpact
- 背景：赤 `D42B2B`／エンブレム内：クリーム `FFF4DC`／文字と縁：黒 `1A1A1A`、アクセントにマスタード黄 `F2B705`（5%以内）
- 大胆な仕掛け：保成の顔がハンバーガーチェーンのロゴのように「商標」化。エンブレムの左右に小さな★
- 情報：店名（アーチ）＋リボン1本＋右下に小さく「ホットドッグ 200円」。以上
- NG：エンブレムの中に文字を入れすぎる、ケンタッキーのカーネル風の直接パロディ（過去例に「SJP」があるので被る）

## C：「はい、どうぞ」（`cut-c`）

**コンセプト**：保成が読者にホットドッグを手渡してくる。パンフを見た人が「受け取る側」になる。

- 手の上に `HOTDOG`（ホットドッグ.png）を重ねて**持たせる**。手のひらの位置を画像内で実測して合わせる（pngjsで写真のアルファを見て手の位置を割り出すか、何度かレンダリングして合わせる）。ホットドッグは手より少し大きめ（遠近で手前に来る感じ）、軽く回転 ±8°

## D：名前がでかい（`cut-d`）

**コンセプト**：「保成をでかでか」を**名前の文字**で解釈する。過去例「道部茶華」のように、文字そのものが絵になる。

- 主役：**「保成」2文字**を画面いっぱいに（縦に「保」「成」を積む or 横並び。どちらか見やすい方をレンダリングで比較して決める）。`HGGyoshotai`（行書）か `HGSeikaishotaiPRO` の筆文字、黒 `1A1A1A`、1文字 約2.6in 角以上（≒190pt）
- 写真：**1000019031**（横顔もぐもぐ）を**落款（ハンコ）サイズ**で右下に。朱色 `C1272D` の角丸四角（約1.5in角）の上に写真を収める（写真の切れた腕は枠の外に出さない）。または写真を朱の円の上に
- 背景：生成り `F5EFE0`＋筆のかすれ風の太い帯（朱 `C1272D`、透明度60%、斜め）を文字の後ろに1本
- 店名：左端に縦書き小さめ（`vText`、`HGMinchoE`、黒）「おいしいホットドック屋さん」
- 補足：なし、または「4年S科」を朱印の近くに小さく
- 色：生成り70／黒25／朱5
- 大胆な仕掛け：店名より人名がでかい。「誰？」と思わせてから店名で回収する
- 注意：白地に近い配色だが、文字が特大なのでOK（「普通サイズの文字」ではない）

**コンセプト**：ドラえもんの「顔がびっしり敷き詰められた」キャラクターグッズ柄のように、**保成の写真を画面いっぱいに敷き詰めて背景**にする。その上に特大の「保成」。

### 背景（この案の主役の仕掛け）
- `images/people/cropped/` の**8枚すべて**を使う（`1000019031` / `1000019035` / `1000019036` / `1000019038` / `1000019040` / `1000019062` / `1000019756` / `1000023102`）。ファイル名で解決すること（インデックス参照禁止）
- 画面全体（6in×6in）に、**隙間が見えないくらい密に**並べる。参考にした柄は「余白がほとんどなく、向き・大きさがバラバラで、少しずつ重なっている」のが特徴
  - 目安：1枚あたり高さ 1.0〜1.8in、7〜9列 × 6〜8段の千鳥配置、段ごとに横方向へ半ピッチずらす
  - 1枚ごとに回転を変える（-20°〜+20°）。大きさも段ごとに変える。同じ写真が隣り合わないように並び順をずらす
  - 端は断ち落とし（画面外まではみ出させて、隙間を作らない）
- 背景色：写真の隙間から見える地色は**淡い水色 `BFE3F5`**（参考柄と同じ発想。ホットドッグの赤黄とは別方向で、他の出店カットとも差がつく）
- **敷き詰めた写真は主張しすぎないよう淡くする**：`addImage` の `transparency`（pptxgenjs が対応していれば 45〜60）を使う。効かない場合は、敷き詰めた上から淡い水色 `BFE3F5` の矩形を `transparency: 45` くらいで全面にかぶせて沈める。どちらでもよいので、**特大文字が読めることをレンダリングで確認して決める**

### 前景
- 特大「保成」（D案と同じ `HGGyoshotai` 系の筆文字、黒 `1A1A1A`）を画面いっぱいに。背景が賑やかなので、**白または生成りの太いフチ**（`outlinedText` の stroke 幅 0.06in 前後）を付けて必ず分離させる
- D案の斜めの朱帯は**残す**（背景の賑やかさを1本の帯が締める）。朱 `C1272D` のベタ。文字と帯の重なりで読みにくくならないか確認
- 落款（右下の朱の角丸＋顔写真）は**残す**。背景と混ざって見えなくなるなら、白い細枠を足して分離する
- 左端の縦書き店名「おいしいホットドック屋さん」は残す（黒、20pt前後）。背景に埋もれるなら、店名の裏に生成りの帯を敷く
- **「ホットドッグ二〇〇円」は入れない**

### 合格条件
- 240px（5cm相当）に縮めたとき、「保成」と店名が読め、背景が「保成だらけ」だと分かること
- 背景のどこかに顔が切れて気持ち悪い部分がないこと（首から下だけの断片が目立たないこと）
