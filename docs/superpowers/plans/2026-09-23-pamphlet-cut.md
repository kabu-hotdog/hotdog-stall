# 高専祭パンフレット用 出店カット — 計画（Opus作成）

- 期限：**2026-09-27(日)**、Googleフォームで提出（学校アカウント必須。形式・サイズ条件は未確認）
- 方針：保成（佐藤保成）をでかでかメインにする（ユーザー案）。手書き必須かは未定なのでまずClaudeで作る
- ワークフロー：`docs/research/2026-09-23-ai-poster-workflow.md`（Opusがブリーフ → ユーザーが方向を選ぶ → Sonnetが1体1案で試作 → Opusが講評 → ユーザーが手直し）

## ジャンル分析（添付の過去パンフ9マスから）

| 記号 | 例 |
|---|---|
| 正方形に近い枠＋黒い太枠 | ほぼ全マス |
| 出店名が特大で一発で読める | 「道部茶華」の4文字タイル、「PAN PAN パンケーキ」 |
| 身内の顔ネタ | 「SJP」＝先生の顔をカーネル風に（身内ウケの最強フック） |
| 既存デザインのパロディ | KEEP CALM ポスター |
| 情報は最小限 | 場所・一言だけ。価格はほぼ書かない |

**設計上の制約**：印刷サイズは1マスで約5cm角。ほかの出店の隣に並ぶ。つまり
1. 5cmに縮めても**店名と保成の顔**が読める
2. 文字要素は**3つまで**（店名／一言／場所か価格）
3. 隣のマスと並んだときに目立つよう、**カラーで高コントラスト**（過去例はほぼ白黒なので、色があるだけで勝てる）

## 共通仕様（全ブリーフ）

- スライド 6in × 6in（1:1）。フォームの条件が分かったら比率を合わせる
- 書き出し：`export-slides.ps1 -Width 3000`（提出用）、QA用は1240
- 素材：`images/people/cropped/` の**ファイル名で指定**。写真は最大530pxと小さいので、保成を枠いっぱいに使うと印刷で粗くなる → **元写真（高解像度）をユーザーに依頼中**
- 店名表記：「おいしいホットドック屋さん」（「ドック」表記は屋台の正式名）
- 場所：4年S科教室
- `safeWriteFile()` 必須。出力は `flyers/pamphlet/`（新規ファイルのみ）
- QA：`poster-knowhow.md` §1 のチェックリスト＋「5cm縮小（幅240px）で店名と顔が読めるか」

## ブリーフ案（ユーザーが選ぶ）

骨格・写真・言い換え先・主要モチーフが全部違うように作っている。

| # | テーマ | 写真 | 骨格 | 大胆な仕掛け |
|---|---|---|---|---|
| A | **ダイナー看板ロゴ** | 038（正面・口開け） | 顔を円形エンブレムに収め、周りに店名をアーチ状に。アメリカンダイナーの看板 | 保成が「ブランドロゴ」そのものになる。赤×黒×クリーム |
| B | **かぶりつきドアップ** | 035（ホットドッグにかぶりつき） | 顔と手元で枠の8割。断ち落とし。左上に特大「うまい。」 | 写真が主役、文字は2つだけ。しずる |
| C | **「はい、どうぞ」** | 040（両手を差し出す） | 手の中にホットドッグ画像を重ね、読者に手渡してくる遠近 | 読み手が受け取る側になる。価格「200円〜」を手元に |
| D | **名前がでかい** | 031（横顔・もぐもぐ）を小さめ | 「保成」2文字を筆文字で枠いっぱいに（道部茶華の文法）、写真は落款サイズ | 「保成をでかでか」を名前の文字で解釈した案 |
| E | **おなかいっぱい** | 062（丸いおなか） | 全身縦長。おなかの丸にホットドッグ本数カウンター風の文字 | おなかに情報を埋め込む（チーズの穴に価格の勝ちパターン） |
| F | **指名手配（既存ポスターと統一）** | 1枚 | WANTED.jpg と同じ世界観の縮小版 | ポスターとパンフでシリーズ感。新規性は低い |

**Opusのおすすめ**：A・B・C（写真を大きく使え、5cmでも顔が立つ）＋D（名前解釈の保険）。Fはポスターとの統一を重視するなら。

## 次の手順

1. ユーザーが案を選ぶ（＋元写真があれば渡してもらう）
2. 選ばれた案ごとに、Sonnetが単体で実行できる詳細ブリーフ（座標・色・フォント・文言・禁止事項・完了条件）をOpusが書く
3. Sonnetサブエージェントを1体1案で並列起動
4. Opusが全PNGを並べて講評 → 修正指示
5. ユーザーに提示 → 手直し → 承認 → 提出用JPG（幅3000px）
